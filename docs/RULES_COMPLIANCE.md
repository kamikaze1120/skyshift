## Can we start now?
- The 2026 Terms & Conditions don't explicitly ban pre-event work, but past official FAQs are explicit: organizers ask participants to start the actual work when the hackathon begins. Treat that as still in force.
- **Safe to do now:** recruit, assign roles, study the data, run IRSA's own tutorials to learn the data, set up repo process/governance files (this repo).
- **Wait for kickoff (Nov 14, 9:00 AM):** application code, UI mockups, even `create-next-app`. Scaffolding takes minutes and isn't worth a disqualification risk.

## Eligibility & participation
- Only U.S. federal civil servants are excluded from participating. Municipal employment does not affect eligibility.
- Everyone participates in a personal capacity, on personal time, using personal accounts and equipment.
- Team cap is **6 people**. Everyone must register on spaceappschallenge.org and join the team page.

## Licensing & citation
- Original content must be freely available or OSI open source — this repo defaults to **Apache 2.0**.
- Submissions can't promote commercial services or products.
- Every source used must be cited, including open-source ones — skipping citations can cost award status. Log everything in `CREDITS.md`.

## AI use
- AI tools are permitted and can be used to accelerate innovation and creativity, with disclosure (see `../AI_USAGE.md`).
- Generated content must not use, contain, or modify NASA branding or design elements (logos, flags, mission identifiers).
- AI-generated images/videos need a visible watermark. AI-generated code/data must be acknowledged in descriptive text and metadata.
- Judges weigh originality, intent, and execution for AI-assisted work.
- The 2026 AI-use guide is unpublished as of this writing (expected ~Nov 13, 2026) — the above is carried over from the 2025 guide; re-check when the 2026 version drops.

## Personal data
- Space Apps forbids collecting personal information from the public. The in-app "flag a mover" feature records **country only** (from request location) — no accounts, no names, no emails.
